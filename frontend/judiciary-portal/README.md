# Judiciary Portal

Secure portal for judges and court officials to access verified digital case files and evidence.

## Features
- **Digital Case Files**: Access FIRs and investigation records
- **Evidence Verification**: Verify evidence integrity with hash checking
- **Audit History**: View complete audit trail of case actions
- **Order Management**: Issue and manage court orders (including FIR amendment authorization)

## Tech Stack
- Next.js 14, React 18, Tailwind CSS, TypeScript

## Getting Started
```bash
cd frontend/judiciary-portal
npm install
npm run dev
```
