# Admin Panel

System administration panel for managing users, roles, policies, and system health.

## Features
- **User Management**: Create, modify, deactivate user accounts
- **Role Management**: Define and assign roles with fine-grained permissions
- **Policy Management**: Configure system policies and thresholds
- **Audit Controls**: Review system audit logs
- **System Monitoring**: Health checks, service status, resource usage

## Tech Stack
- Next.js 14, React 18, Tailwind CSS, TypeScript

## Getting Started
```bash
cd frontend/admin-panel
npm install
npm run dev
```
Access at `http://localhost:3002`
