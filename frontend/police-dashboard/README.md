# Police Dashboard

Internal dashboard for police officers to manage FIRs, investigations, and evidence.

## Features
- **FIR Management**: Create, view, and track FIRs (tamper-proof)
- **Investigation Center**: Case management and officer assignment
- **Evidence Review**: Review uploaded evidence with AI analysis
- **Alerts**: Real-time alerts for high-priority cases
- **Reporting**: Generate investigation reports

## Tech Stack
- Next.js 14, React 18, Tailwind CSS, TypeScript

## Getting Started
```bash
cd frontend/police-dashboard
npm install
npm run dev
```
Access at `http://localhost:3001`
