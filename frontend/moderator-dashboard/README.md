# Moderator Dashboard

Dashboard for content moderators who review social media content flagged by AI.

## Features
- **Content Review**: Review AI-flagged social media content
- **Appeals**: Process citizen and officer appeals
- **Social Media Cases**: Manage cases generated from social media monitoring
- **Risk Analysis**: View AI risk scores and recommendations
- **Temporary Evidence Review**: 3-5 day evidence review workflow

## Key Workflow
1. AI flags social media content
2. Moderator reviews flagged content
3. Content marked as temporary FIVR (Flagged for Investigation and Verification Review)
4. Citizen given 3-5 days to upload complete evidence
5. Moderator verifies and converts to permanent FIVR or removes

## Tech Stack
- Next.js 14, React 18, Tailwind CSS, TypeScript

## Getting Started
```bash
cd frontend/moderator-dashboard
npm install
npm run dev
```
