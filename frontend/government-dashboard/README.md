# Government Dashboard

Dashboard for government oversight authorities to monitor police accountability and employee conduct.

## Features
- **Employee Monitoring**: Track officer activity and performance
- **Accountability Score**: View and manage integrity scores
- **Disciplinary Review**: Process misconduct cases and fines
- **Audit Tracking**: Compliance monitoring and audit trails

## Tech Stack
- Next.js 14, React 18, Tailwind CSS, TypeScript

## Getting Started
```bash
cd frontend/government-dashboard
npm install
npm run dev
```
