# Citizen Portal

Public-facing web application for citizens to interact with AI PoliceNet.

## Features
- **Public Reporting**: File complaints and reports
- **Complaint Tracker**: Real-time status tracking
- **Evidence Upload**: Secure file upload with hash verification
- **Notifications**: Case updates and alerts
- **Profile Management**: Manage personal information
- **Emergency Reporting**: One-tap emergency alerts

## Tech Stack
- Next.js 14
- React 18
- Tailwind CSS
- TypeScript

## Getting Started

```bash
cd frontend/citizen-portal
npm install
npm run dev
```

Access at `http://localhost:3000`
