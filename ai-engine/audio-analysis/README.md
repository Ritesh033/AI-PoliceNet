# Audio Analysis

Audio processing models for evidence analysis and threat detection.

## Models
- **Speech-to-Text**: OpenAI Whisper for multilingual transcription
- **Threat Identification**: Audio classifier for threatening content
- **Voice Analysis**: Speaker embedding for identification and verification

## Supported Languages
- English, Hindi (primary)
- Regional Indian languages via Whisper multilingual

## Input Formats
- MP3, WAV, OGG, M4A, FLAC
