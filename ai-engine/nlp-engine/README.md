# NLP Engine

Natural Language Processing models for text analysis.

## Models
- **Text Classification**: Categorize complaints, reports, and social media content
- **Threat Detection**: Identify threatening language in real-time
- **Hate Content Detection**: Multi-label hate speech classifier
- **Sentiment Analysis**: Emotional tone analysis for complaints and social media
- **Entity Extraction**: Named Entity Recognition for persons, locations, dates, organizations

## Languages Supported
- English
- Hindi
- Regional Indian languages (planned)

## Training
Models are fine-tuned on domain-specific datasets with regular bias audits.
