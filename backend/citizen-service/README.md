# Citizen Service

Manages citizen profiles, complaints, reports, and notifications.

## Features
- **Profiles**: Citizen registration and profile management with unique Registration ID
- **Complaints**: File, track, and manage complaints
- **Reports**: Submit incident reports
- **Notifications**: Citizen notification preferences

## Registration ID Format
```
CIT-{STATE}-{YEAR}-{SEQUENCE}
Example: CIT-UP-2026-001245
```
