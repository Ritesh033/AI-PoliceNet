# Notification Service

Multi-channel notification delivery for all AI PoliceNet users.

## Channels
- **SMS**: OTP, case updates, emergency alerts
- **Email**: Detailed notifications, reports, legal notices
- **Push**: Mobile app notifications
- **Emergency Alerts**: Priority alerts to officers and control rooms

## Notification Types
| Type | Channels | Priority |
|------|----------|----------|
| OTP | SMS, Email | High |
| Case Update | Push, Email | Normal |
| Emergency | SMS, Push, Email | Critical |
| Legal Notice | Email, SMS | High |
| System Alert | Push | Normal |
