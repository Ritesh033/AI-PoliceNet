# Analytics Service

Provides dashboards, trend analysis, heatmaps, and reporting for AI PoliceNet.

## Features
- **Dashboards**: Real-time metrics for each user role
- **Trends**: Crime trend analysis over time
- **Heatmaps**: Geographic visualization of incidents
- **Reporting**: Automated and on-demand report generation

## Key Metrics
- FIR registration rates
- Case resolution times
- Officer response times
- Social media flag volumes
- Evidence processing times
- Regional crime patterns
