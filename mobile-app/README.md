# Mobile Applications

## Overview

AI PoliceNet provides three mobile applications for different user roles.

## Applications

### Citizen App
- File complaints on the go
- Upload photo/video evidence
- Track case status
- Receive push notifications
- Emergency SOS button with GPS

### Officer App
- View assigned cases
- Update FIR status in the field
- Capture and upload evidence
- Receive alerts and dispatches
- GPS-based location tracking

### Emergency App
- One-tap emergency reporting
- Automatic location sharing
- Live audio/video streaming to control room
- Contact emergency services
- Send alerts to nearby officers

## Tech Stack
- React Native / Expo
- TypeScript
- Redux Toolkit
- React Navigation

## Platforms
- Android (API 24+)
- iOS (15.0+)

## Getting Started

```bash
cd mobile-app/citizen-app
npm install
npx expo start
```
