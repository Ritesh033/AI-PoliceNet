# Integrations

External service integrations for AI PoliceNet.

## Services

### SMS Gateway
- OTP delivery
- Emergency alerts
- Case status notifications

### Email Gateway
- Detailed notifications
- Legal notices
- Report delivery
- SMTP with TLS

### Maps
- Google Maps API for geolocation
- Geofencing for jurisdiction boundaries
- Incident location mapping
- Crime heatmap generation

### Identity Verification
- Aadhaar-based verification (where applicable)
- Government ID verification
- Biometric verification support

### Digital Signature
- PKI-based digital signatures
- Document signing for legal records
- Certificate management
- Signature verification API

### Public Records
- Integration with existing government databases
- Court records access
- Criminal history lookup (authorized access only)
- Vehicle registration database
